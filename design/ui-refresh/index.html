What changes, in five lines

Navigation
Top tab strip → desktop sidebar + mobile bottom tab bar (5 slots; Ledger/Payments/My-spend fold into Money).
Look
Untitled UI tokens: Inter, gray-25…950, teal brand scale (your #0F766E ≈ teal-700 — the brand survives), radius 12 cards, pill badges with status dots.
Icons
Lucide-style 2px stroke icons in Untitled UI featured tiles; emoji remain only as user content (a trip picks its own badge).
Signature
The Plan becomes a numbered day rail whose nodes are literally the map pins.
Mobile
48px touch targets, thumb-zone navigation, safe-area insets, one-hand reachable actions.
Dark mode
Free at the token layer — toggle on every page of this prototype.

Noted for the real build (beyond this mockup)

  • Route lines by transport mode — the day map draws each leg in its mode's style (train solid teal · walk dotted gray · taxi dashed amber). The app already computes per-leg modes, so this is a straight Leaflet polyline-style mapping.
  • Navigation v4 — Home always opens the trips folder; trip pages get a fixed, collapsible sidebar (icons-only rail, choice persisted). On mobile, long-press Plan/Money/Docs in the tab bar to open the trip switcher sheet; More holds People, Settings, Admin, log out. Real build: same localStorage persistence, plus per-user server-side once settings sync lands.
  • Auth carousel — login page cycles destination photography (Ken Burns crossfade, 6s, paused for reduced-motion). Mock uses random picsum seeds, so photos won't match captions — real build ships 5–6 curated, licensed images bundled as static assets (no API needed).
  • Trip covers — leader uploads an image (KV, same store as documents) or Jelajah auto-fetches one for the destination from a keyless source (Wikimedia/Wikivoyage page image via geocode). Mock uses placeholder photos.
  • Theme setting — Light / Dark / System persisted per user (localStorage first, `users` column later so it follows logins).
