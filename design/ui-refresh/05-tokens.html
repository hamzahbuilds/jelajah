Layout rules

  • Desktop ≥1024px: 264px sidebar (trip switcher, grouped nav, user footer) + content column max 1120px.
  • Mobile: sticky slim top bar + 5-item bottom tab bar (Home · Plan · Money · Docs · More), 48px targets, safe-area padding.
  • Page header: breadcrumb-eyebrow, h1, one-line purpose, actions right — every page, same bones.
  • 8px spacing grid · cards gap 20 · section gap 24.
  • Dark mode ships from the token layer — try the 🌗 button.
